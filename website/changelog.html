Changelog

更新日志

摘录近期版本的主要变化，完整日志仍保留在仓库的 `res/demo/README_Update.md` 中。

2026.05.23

Neri 3.0.3-beta

  • 设置页新增当前版本信息，“项目信息”调整为“关于”，并提供反馈与源码入口。
  • 新增调试模式页面，可复制运行环境、GPU/PyTorch 状态、依赖状态与日志信息。
  • 优化启动加载、关闭流程、FP16 可用性判断和开始界面删除任务提示。
  • 校验界面按当前置信度重新计算物种分组，低阈值结果归入过滤后的分组。
  • 修复 Windows 端后端连接后可能闪退、父进程监听误判等问题。
2026.05.20

Neri 3.0.2-beta

  • 校验界面支持批量撤回，并在基础设置中新增撤回步数配置。
  • 快速标记和批量标记改为批量提交，减少大量请求造成的末尾卡顿。
  • 检测依赖缺失时，相关模型、视频、阈值和 FP16 设置会自动禁用。
  • 修复撤回只能回退一步、部分按钮高度不一致和安装路径提示不直观的问题。
2026.05.18

Neri 3.0.1-beta

  • 移植部分功能，完善前后端拆分后的交互。
  • 修复若干 beta 版本中的已知问题。
2026.05.17

Neri 3.0.0-beta

  • 使用 Flutter 编写 Material 3 风格前端，提升应用界面流畅程度。
  • 大部分功能完成迁移，作为 beta 版本发布。
部分 AVI 格式视频可能无法识别，暂不支持 Windows 7。Intel GPU 支持仍为实验性，在部分设备上可能报错。
