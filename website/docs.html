使用文档

这份文档整理了 README 中最常用的操作路径，适合第一次使用 Neri 或需要部署源码环境时快速查阅。

快速开始 处理流程 模型设置 显卡加速 源码运行

快速开始

  1. 前往下载页或 GitHub Releases，下载最新 `.zip` 或 `.7z` 压缩包。
  2. 将压缩包解压到任意本地目录。
  3. 双击 `Neri.exe` 启动程序。首次使用需要联网准备相关依赖，之后可离线使用。

处理流程

  1. 在开始界面点击“选择图片”，选择包含红外相机照片或视频的文件夹。
  2. 根据设备性能选择模型文件、分类模型、视频识别模式、置信度和 IOU 阈值。
  3. 点击“开始处理”，等待任务进度完成。
  4. 进入校验页面查看识别结果，并按实际情况修正物种或数量。
  5. 在预览页面点击“导出”，将结果保存为 `.xlsx` 或 `.csv`。

模型设置

模型目录位于 `res/model` 和 `res/model_cls`。目前主要支持 `.pt` 模型文件，可以根据地区、目标物种或设备性能自行替换。

置信度阈值 控制检测结果的最低置信度，较高数值可减少误检，但可能增加漏检。
IOU 阈值 控制非极大值抑制的重叠阈值，影响重复框过滤效果。
视频跳帧 通过帧间隔提升视频处理速度，适合长视频或批量监测数据。

显卡加速

如果 Windows 设备配备 NVIDIA GPU，建议启用 CUDA 版本依赖以获得更快推理速度。Intel Arc 独显和部分搭载 Intel Arc Graphics 的平台支持 XPU 版本，但仍属于实验性能力。

  1. 右键桌面，打开 NVIDIA 控制面板。
  2. 在“帮助”中打开“系统信息”。
  3. 查看 `NVCUDA64.DLL` 等条目，确认对应 CUDA 版本。
  4. 回到 Neri 的高级设置，在“环境维护”中选择对应 PyTorch 版本安装。

源码运行

后端基于 FastAPI，前端基于 Flutter Material 3。开发运行时可分别启动：

python -m pip install -r requirements.txt
python -m uvicorn system.backend.main:app --reload --app-dir . --host 127.0.0.1 --port 721
cd frontend
flutter pub get
flutter run
