快速开始

下载发布包后解压，双击 `Neri.exe` 启动。首次使用需要联网准备依赖，后续可用于离线处理本地影像数据。

处理流程

  1. 在开始界面选择包含红外相机照片或视频的文件夹。
  2. 选择模型文件、视频处理方式、置信度与 IOU 阈值。
  3. 启动任务后进入预览与校验页面复核结果。
  4. 导出 `.xlsx` 或 `.csv`，用于后续统计分析。

显卡加速

NVIDIA GPU 推荐使用 CUDA 版本 PyTorch；Intel Arc 和部分 Intel Arc Graphics 平台可尝试 XPU 版本，但仍属于实验性支持。

源码运行

开发环境可分别启动后端与前端：

python -m pip install -r requirements.txt python -m uvicorn system.backend.main:app --reload --app-dir . --host 127.0.0.1 --port 721
cd frontend flutter pub get flutter run
