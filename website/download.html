运行建议

更稳定的本地处理环境

Windows 桌面

当前发布版以 Windows 桌面使用为主，暂不支持 Windows 7。

可用存储空间

模型文件、依赖与批量影像会占用较多空间，建议预留充足磁盘容量。

GPU 加速

NVIDIA CUDA 与 Intel XPU 可提升推理速度，Intel GPU 支持仍为实验性。
