# 任务历史弹窗与模型名称

开始页的任务列表移入“开始处理”按钮右侧的圆形“任务历史”按钮。
弹窗支持查看进度、停止、继续、重试失败文件、展开结果、删除和清除任务。
没有历史任务时也可以打开，并显示空状态。

弹窗复用主窗口现有的任务轮询，不启动额外的定时器。父组件更新任务、
按钮等待状态或详情加载状态后，通过 ValueNotifier 在帧结束后同步到弹窗。
任务按 ID 保持展开状态；关闭弹窗会取消详情展开订阅，避免继续加载隐藏历史。
关闭开始页时会移除关联弹窗，通知器等路由退出后释放。

任务进度、恢复特征提示和序列汇总从分类模型清单的 `display_name` 读取名称。
运行时把名称传给分类器，用于完整、部分和空照片序列的汇总消息。
名称缺失时使用“联合模型”，不根据共享 DINOv3 后端猜测模型版本。

检测框详情、候选验证、模型设置、补图、组件下载和维护等共用提示使用中性文案。
历史检测框的“模型预测”保留原始预测值；缺少检测框标识时仍不能提交学习反馈。
组件状态卡展示服务端返回的实际组件名称和架构。

生产与预览模型的正式默认名称分别集中定义为 `PRODUCTION_DISPLAY_NAME` 和
`PREVIEW_DISPLAY_NAME`；离线训练、模型发布及清单中的真实版本名称保持其含义。
