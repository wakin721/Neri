# DINOv2 Memory 去质心默认分类头

nightly 的新 DINOv2 组件安装会把下载到的旧多原型分类头替换为随应用附带的 `res/dinov2/memory_no_centroid.npz`。已有安装需在环境页面重新安装 DINOv2 组件，才会使用新默认头。显式选择的旧多原型模型仍可读取。

“去质心”指分类分数不混入类别质心相似度（`centroid_weight=0`）。特征仍使用冻结的类均衡中心进行 CL2N 变换。每个类别先在每台相机内取最高相似度，再取至多 3 台相机的均值；取分数最高的类别。拒识分数为获胜类别分数加上第一、第二类别的分数差，低于独立校准阈值才拒识。

随附模型来自 `Neri_plus/runs/training_free_head_20260921/features` 的 66 类冻结 DINOv2 特征。5,914 张图构成记忆库，另外 2,468 张来自独立相机的图用于 4% 目标误拒率校准。阈值为 `0.4693286418914795`，相等时接受。模型 SHA-256 为 `0d72e19cb55642f5df681165281baecb4cbbd6340635f31f24b17da0ef4ed5c1`；编码器 `model.safetensors` SHA-256 为 `d73036b56966966d07975d696bde331762f37297e2f095de8cea0040c3aa0841`。详细类别、相机校准和数据来源记录在 `res/dinov2/memory_no_centroid_manifest.json`。

已登记的正式物种事件和已激活反馈代中审核通过的事件会按相机加入当前 Memory 评分；反馈质量检查使用相同的获胜分数与类别间隔，未通过时保留上一代的样本快照。临时登记物种只提供辅助提示。阈值是对冻结基础记忆库校准的，动态样本加入后没有独立的新相机校准保证。该 66 类模型也没有完整独立测试集，不能套用较小类别对照实验的准确率。
