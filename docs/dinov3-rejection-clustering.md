# 拒识目标 HDBSCAN 聚类

实现分支：`codex/hdbscan-rejection-clusters`。

## 使用范围

同一个 Neri1.1 识别任务选择的所有文件夹共同参与聚类。等待所有照片完成完整序列判定后，取最终 `accepted=false` 的检测框统一拟合一次 HDBSCAN。正式模型与实验模型均支持；两者原有物种预测、分数、拒识门限不变。

开启自动分组时，保留原有连拍分组，以整组内物种和簇的组合划分物种列表。例如同组中有簇1与簇2，列表显示“簇1、簇2”；包含已知物种时可显示“豹猫、簇1、簇2”。整组只归入对应组合条目，不再因成员簇不同拆成多个分组。簇编号去重并按数字排序，相同组合的分组汇集在同一条目。关闭自动分组时，继续按单个簇浏览，一张多目标照片可出现在多个簇中。

未成簇、尚待处理和聚类失败分别显示。未校验的普通物种排在前面，随后是拒识簇、未成簇、空，人工校验完成的条目排在空后面。聚类分组是浏览元数据，不移动原照片，不把簇名写成真实物种。逐框人工校验与学习入口保留，聚类不会自行学习或整簇赋予物种。

预览与校验图像的检测框在有有效簇记录时显示“簇1”“簇2”等，并依据簇编号使用固定、不同的颜色，框线与文字背景使用相同颜色。原有目标序号、分类证据分数继续保留。人工确认的真实物种名优先，过期或未完成序列的簇信息不作为显示依据。此规则只改变显示，原始物种和拒识结果仍保存为 Unknown，不会将簇标签加入训练。

旧任务没有聚类元数据时显示未聚类，需要重新执行识别任务生成结果。当前版本不在打开页面或查询分批接口时临时拟合，也不自动把不同任务的历史拒识库合并。

## 特征与独立样本

复用当前任务已经提取的动物裁剪 DINOv3 原始特征，不额外加载编码器、不用物种分类分数代替视觉特征，也不使用跨事件历史适配后的特征。

复用已有目标关联算法，以完整源目录作为稳定相机代理，独立建立用于聚类的 `(camera_id, track_id)`，避免选择文件夹的顺序或共同根目录改变代表样本。原分类器使用的上下文保持原样。实验模型聚类也使用目标轨迹，而不是其整事件拒识分组。相同文件内容与相同裁剪框的跨目录副本合并，副本连接的轨迹合并为同一独立目标。每个目标内按唯一裁图取单位特征平均，再归一化。目录不等同于真实相机，轨迹由启发式关联产生，也不保证是真实独立个体。

独立目标数与特征维度均超过 32 时，执行固定随机种子的 PCA 到 32 维，不对中心化后的投影再次归一化，以保留密度几何；小样本保留原特征。HDBSCAN 使用 scikit-learn 实现（依赖已由 `requirements.txt` 的 scikit-learn>=1.3,<2 提供），欧氏距离、`min_cluster_size=5`、`min_samples=3`、`cluster_selection_method=eom`，`n_jobs=4`，BLAS 线程上限 4。保留默认 `allow_single_cluster=False`，不强制把单一密集团整体命名为一个簇；即使照片相似，也可能全部未成簇。未达到成簇条件的照片保留为未成簇，不强行划分。

这些参数是首版固定配置，尚未通过真实拒识照片验证最优性。照片数量、姿态、背景与日夜模式均可能影响簇；一个簇不能视为一个已确认物种，成员强度也不是物种正确概率。

## 保存与恢复

每个拒识检测框保存 `rejection_cluster`，包括运行标识、簇标识、显示编号、模型指纹、独立目标数、状态和算法配置。模型指纹由编码器与分类头检查点 SHA-256 组成。运行标识绑定任务、成员、特征、参数与 sklearn 版本；输入顺序固定，避免文件夹选取顺序影响编号。

元数据随现有检测数据库和任务结果保存，经过后端检测框规范化和前端 JSON 解析后仍然保留。界面直接读取已保存成员关系，查询分页不会把全局聚类拆成局部聚类。重新识别会产生新快照，簇编号不承诺跨任务或数据集变更保持一致。

取消任务时不提交聚类结果；不完整序列会清除已有簇元数据。HDBSCAN/PCA 在一次底层调用期间不能立即中断，调用返回后再次检查取消状态。聚类异常记录日志并保存失败状态，成功的物种判定仍可使用。

## 验证

覆盖真实 HDBSCAN 的合成特征分组、输入乱序、跨文件夹重复与轨迹去重、接受样本排除、完整序列保存、规范化后重载、取消与失败处理，以及界面分簇与逐框反馈。

初版验证：后端相关测试 137 项通过，前端组件与回归测试 67 项通过。后续组合分组和框颜色更新增加了簇名与稳定颜色、人工确认优先、原始检测记录恢复、520 张照片的异步整组组合，以及逐框改正后组合刷新的测试。保留原有大列表局部校验更新，簇变化只更新组合成员关系，不按簇拆开连拍组。新增显示逻辑不需要重新提取特征或重新拟合 HDBSCAN；已有簇元数据可直接显示。

组合分组和框颜色更新的最终前端回归共 72 项通过；Windows Release 构建通过，静态检查无错误和警告，保留原有样式提示。

性能检查：本机 10,000 条 768 维合成特征、20 个预设密集群，共识别 20 个簇、未成簇 0，约 2.15 秒。该数据只用于检查运行规模，不代表真实动物照片的准确率或实际耗时。

主要代码：`system/dinov3/rejection_clustering.py`、`system/dinov3/processor.py`、`system/dinov3/runtime.py`、`system/backend/services_legacy.py` 与前端物种校验界面。

部署使用 `scripts/deploy_dinov3_rejection_clusters.ps1`，逐文件备份并校验 SHA-256，失败时自动回滚。安装结果与原文件保存在安装目录 `repair-backups/rejection-clustering-*/inventory.json` 及同目录 `files/` 中。旧任务仍需重新执行识别才能生成聚类记录。
