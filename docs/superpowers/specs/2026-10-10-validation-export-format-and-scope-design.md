# 校验结果导出格式与目录范围设计

## 目标

物种校验页的导出区仅显示“导出”按钮，外层面板与同页置信度面板等高。用户可在“设置 → 基础设置”选择 CSV、Excel 或每次询问。选中总文件夹下的子文件夹时，用户可在导出时选择当前子文件夹或全部目录；全部目录中的每个含媒体目录分别得到自己的表格。

## 现状与约束

- 校验页当前显示 CSV/Excel 分段选择器及导出按钮，选择只保存在页面静态状态中。
- 收藏媒体的导出询问使用 `AlertDialog`、“不再询问”复选框和保存设置回调；新格式弹窗沿用这一交互。
- 主窗口的目录浏览状态同时保留输入的总路径和当前选中的子目录。现有导出请求只接受一个 `input_path`，后端把递归找到的全部媒体合并为一份表格。
- 现有收藏媒体导出及空照片删除均受导出请求内的媒体路径集合约束。

## 交互流程

1. 导出区移除格式选择器，按钮文字固定为“导出”。面板采用与置信度面板一致的外层高度和间距；导出期间按钮禁用并显示进度。
2. 当总路径是目录且当前选择的是其子目录时，先弹出范围询问，选项为“仅导出当前子文件夹”“导出全部目录”“取消”。当前子文件夹包含其下层目录；“全部目录”使用总路径。其他情况直接使用当前输入路径，不额外询问。
3. 格式设置为 `ask` 时弹出 CSV/Excel 选择窗口，采用收藏媒体询问窗口的样式，提供“不再询问”。勾选后将所选格式保存为固定偏好；取消即停止此次导出。设置为 `csv` 或 `excel` 时直接使用该格式。旧配置或非法值归一为 `ask`。
4. 然后沿用已有的空照片删除和收藏媒体询问。各自检查、计数和实际处理都使用此次选择的目录范围；取消任一步都不发出导出请求。
5. 成功提示显示生成表格数、记录数和可打开的输出位置；单文件时保留已有的详细提示。失败时显示错误；如果多文件导出出现部分完成，错误需说明已生成哪些文件，不把它报告为完整成功。

## 前端与设置

- `settings_screen.dart` 的基础设置新增“导出格式”，值限定为 `ask`、`csv`、`excel`，默认 `ask`，通过现有设置保存机制持久化。
- `main_window.dart` 向校验页传入总路径、当前选中路径、格式模式和保存格式模式的回调。校验页负责对话框顺序与取消处理，向 API 提交明确的导出范围和格式。
- API 客户端和结果模型增加批量输出文件列表，保留原 `output_path` 以兼容单文件调用及现有调用方。

## 后端导出

- 请求增加可选的逐目录导出标志；缺省为现有单文件行为。前端选择“导出全部目录”时以总路径和逐目录标志请求。
- 后端只遍历所选路径内的受支持媒体。逐目录模式按媒体的直接父目录分组；总目录本身有媒体时也单独成组。每个组只包含该目录直接持有的媒体，并在该目录生成带时间戳及所选扩展名的表格。没有媒体的目录不生成空表。
- 继续按目录独立处理检测结果和工作日数据，复用现有列选择、置信度、帧占比、格式转换及文件命名逻辑。
- 收藏媒体按每个输出表格所属的媒体集合复制到对应目录的收藏媒体输出目录。空照片删除只作用于本次范围内明确请求的媒体。
- 响应提供所有表格路径与合计记录数、收藏媒体数、删除数。保留单路径字段供旧客户端使用。批量执行中若某目录失败，应返回明确的部分完成信息及已创建文件路径。

## 验证

- Python 测试覆盖原有单文件模式、嵌套目录逐目录输出、总目录自身媒体、空目录跳过、CSV/Excel 扩展名、记录不跨目录混入，以及收藏媒体和空照片操作的范围。
