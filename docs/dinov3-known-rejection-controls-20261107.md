# 已校验已知物种的误拒对照池

每个已知物种默认取最多 **50 个独立连拍、每个连拍一张**，标记为“应被接纳”，用于检查拒识门控是否误拒已知物种。按固定种子优先覆盖不同相机与连拍，取样只读取标签与身份信息。训练流程在拟合前固定名单，并保存其哈希。

本轮从已有 C 集补建对照，覆盖全部 **45 个已知物种、634 张照片**。其中 38 个物种的可用独立事件不足 50 个，按实际数量全取；每个物种的数量均单列。训练库和最终留出集继续与 C 隔离。

使用当前已安装模型的完整 C 集分数检查：634 张“应接纳”照片中有 **294 张被拒识**，按物种等权的抽样宏误拒率为 **45.32%**。完整 C 集中 24,694 张已知类照片的宏误拒率为 **45.69%**。原有 42 个辅助未知物种、118 张照片继续保留，其宏拒识率为 **90.01%**。

这些结果说明当前门限仍偏严格。本次扩大的是可追溯的误拒检查，模型参数及门限保持原值。抽样报告同时保留完整 C 集参考；少量独立事件的物种仍不适合据此声称精确的物种误拒率。报告属于校准诊断。

在安装目录的 `docs/rejection_validation` 查看：

- `samples.csv`：逐图路径、物种、应接纳标记、预测、门控分数与误拒结果。
- `per_species.csv`：各物种抽样数量及误拒情况。
- `selection.json`：固定样本索引和数据指纹。
- `pool.jsonl`、`report.json`：完整校验清单与报告。
- `known_acceptance_controls.npz`：抽样特征和完整上下文下的原始分数；用于核查，分数不能按独立单图重算后直接比较。
