## 分类结果

针对 `IMAG2421.JPG`、`IMAG2937.JPG` 的原始记录，探测器已正确给出 `person`，后续照片事件融合却把人物框覆盖成家羊。现在照片和视频都按各自目标轨迹进行物种融合，不再把同一照片事件中的不同目标共享为一个分类序列。人员、车辆和动物类别不能关联到同一轨迹，也不能混用历史特征。

对于具有明确通用类别名称的探测器，`person`／`vehicle` 保留为人员／车辆，并使用探测置信度；不根据任意模型的数字类别猜测类别含义。界面显示「探测保留」和「探测证据」，不为这些框伪造 DINO 事件门限。编码器、模型权重和拒识门限保持原值。

历史自动结果可根据保留的 `names_map`、原始类别与置信度安全校正读取视图，保留原始分类摘要和目标 ID；无法对齐时不猜测。人工确认、整图人工标注、人工校验状态均优先。读取不会重写原数据库、图像、人工标签或训练数据。视频数量按每帧最大数统计，人工标为空的框不计入目标数。其他历史动物分类不会仅靠显示层重新推理，需要重新识别才能使用新的轨迹融合结果。

已使用真实探测器和 DINO 模型只读重放原图：`IMAG2421.JPG` 为人员；`IMAG2937.JPG` 为家羊 1、人员 1。人物框使用真实探测置信度约 0.840／0.703。这是针对已报告错误的功能验证，不代表整个数据集的准确率评估，也没有重新校准门限。

## 视频播放

### 点击详情与分组稳定性（2026-11-17 补充）

`IMAG1136.MOV` 的目录快照使用文件时间 `2025-11-22 16:32:32`，单文件详情返回容器时间 `2025-11-22T16:32:22+00:00`。旧界面把它和本地照片时间按绝对时刻比较，点击时重新排序、拆开三张照片加一个视频的组，继而改变组数和物种桶。

现在照片、视频均比较相机记录中的时钟字段，不换算时区。详情合并只补充拍摄时间、尺寸、文件大小与原始 capture_time，保留当前识别结果、拒识簇和人工校验，并保存当前目录快照的分组时间。普通查看不会重排、拆组或覆盖新标注；真实重新扫描和分组设置变更仍可重建分组。前端主窗口、大目录 isolate 排序和校验页的边界判断使用同一时间规则；后端视频参考与历史比较同步采用该规则，时间策略版本升至 4。

包含拒识的混合组先拆分已知物种再去重，标题及物种桶标识共同规范化；`人员` 与 `人员、家羊` 合并成 `人员、家羊`，独立拒识簇仍保持各自编号。

播放器独立维护当前媒体会话和用户播放意图，串行执行打开、播放、暂停与跳转；切换时重置旧时长、进度和播放状态，隔离旧完成事件与错误。隐藏页面暂停但不丢失播放意图，返回后恢复。失败画面提供原路径重试，并记录经敏感信息清理的播放错误。

回归测试覆盖打开过程中旧完成事件、加载中切换与点击、隐藏／显示、重播、错误及同路径重试。原生播放器现场点击验证需要 Windows 应用访问授权；此前窗口访问授权超时，因此不能将模拟后端测试视为当前机器上的原生渲染保证。
