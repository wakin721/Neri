# 视频独立轨迹与三级参考时间（V4）

选择 DINOv3 分类模型并将视频模式设为「快速识别」后，策略 V4（`media_sequence_version = 4`、`classification_scope = "video_track"`）严格隔离视频分类与时间参考：视频不再与照片或其它视频共享分类投票或拒识统计，跨媒体仅通过严格的因果历史上下文发生关联。

## 轨迹隔离与无权重分类

- 在 `production_dual` 与 `experiment_full` 两种推理配方下，每段视频始终按其自身的目标轨迹（以 `video:` 为前缀的轨迹序列 ID）独立进行分类与拒识判定，同帧不同目标分别对应独立轨迹。
- 照片序列事件分组（同相机目录按拍摄时间排序、间隔 30 分钟切分）保持不变，且照片序列与视频轨迹的分类序列 ID 互不相交。
- 因视频不再与照片混合投票，分类器调用不再传入 `evidence_weights`，沿用原本的无权重轨迹内融合统计；纯照片任务保留原流程。
- 跨媒体历史仅用于因果原始特征检索：仅同相机目录下严格早于当前观测参考时间的历史原始特征可进入候选池；同视频的更早采样帧、未来时间观测、其它相机目录以及无绝对时间视频不作为外部历史，每条视频轨迹对外最多贡献一个历史候选。

## 三级参考时间与保守回退

视频参考时间（`video_reference`）按以下优先级解析：

1. `video`（`precision = "exact"`）：视频自身容器内存在可信拍摄／创建时间标签（无 ffprobe 时也会读取 MP4/MOV 与 AVI 的受限元数据区）。采样帧时间在视频起拍时间上叠加帧偏移秒数。
2. `burst_group`（`precision = "group_anchor"`）：视频自身缺少可信嵌入时间，但能明确关联到同一相机下已结束的可靠连拍照片组。
3. `none`（`precision = "unknown"`）：既无自身可信时间，也无法无歧义地归属可靠连拍组，不接入任何外部绝对时间历史，仅保留视频内部相对帧顺序用于目标轨迹关联。

用户于 2026-11-17 补充确认照片和视频使用统一的相机时钟，无需时区换算。界面排序、连拍分组和后端视频参考时间均比较记录中的年月日时分秒，不按容器的 `Z`／偏移标签增减小时。原始时间及偏移元数据仍保留；内部比较值统一使用 UTC 标记承载原样时钟字段，仅为稳定计算与序列化，不代表真实 UTC 时间。签名与结果记录 `camera_clock_policy = "recorded_wall_time"`，不复用旧时区策略的决策。

回退策略保持保守：程序**绝不使用**文件修改时间（`mtime`）、文件创建时间、解码完成顺序或任意相邻文件推测视频拍摄时间。当回退到 `burst_group` 或 `none` 时，不伪造视频拍摄时间或每帧绝对时间戳，结果项的 `date_taken` 保持为空（`None`）。

## 后端文件名连拍证明与可靠组下界

- 自动连拍关联使用同相机目录内连续的文件名计数器作为成员证明（例如 `IMG_0001.jpg`、`IMG_0002.jpg`、`IMG_0003.jpg` 紧接无嵌入时间的 `IMG_0004.avi`）。文件名计数器相邻关系**仅用于证明连拍组成员归属，绝不从文件名数字推算拍摄日期或时刻**。
- 触发自动 `burst_group` 需满足：同目录、同前缀、同编号宽度的未受污染连续照片组（默认满 3 张、照片均具可信拍摄时间、时间单调不倒序且相邻间隔不超过 30 秒），且紧接其后为唯一无冲突的目标视频（其后无紧邻视频或重复编号歧义）。已显式持久化的同相机无歧义 `burst_group_id` 同样需校验组内时间一致性与间隔上限。
- 当组内时间无效、缺漏、倒序、间隔超限或成员归属存在任何歧义时，一律退回 `none`。
- 对成功的 `burst_group`，`reference_time` 取组内**最早**有效照片拍摄时间，仅作为保守的历史时间截断下界（cutoff），同时记录 `group_end_time`、`burst_group_id` 与 `group_members`；同组照片不会作为更早历史注入视频。

## 缓存、版本失效与续跑

- 保留内存解码、预取与自动批量重试，不落盘临时 JPEG；照片与视频裁图各自只编码一次。
- 完整视频采样帧特征以 SQLite 事务缓存，签名包含源文件大小／修改标识、帧完整性、分组配置与 `media_sequence_version = 4`。升级后旧版已完成决策不再沿用；兼容的原始特征缓存保留。
- 持久化结果保留真实源文件 `observation_id`、帧索引与秒位置定位，拒识保留 Unknown；取消时标记部分完成并保留断点。

## 模型阈值与验证边界

本更新保留原有编码器 FP32 协议、模型权重、训练支持与全部固定拒识阈值，**未对固定阈值重新训练或重新校准**，也不宣称推理速度提升或真实数据集准确率提升。

安装后验证脚本 `scripts/verify_mixed_media_installation.py` 支持 `--scenario own|burst|none`（默认 `own`），分别构造含嵌入时间 AVI、连续计数器连拍照片加无时间 AVI、以及无时间孤立视频三类可丢弃本地相机样本，校验 `media_sequence_version == 2`、`classification_scope == "video_track"`、`video:` 轨迹隔离、无 `evidence_weights`、真实 `observation_id`/帧位置及回退场景下 `date_taken` 为 `None` 等约束。运行时关闭自动学习快照选择，模型与原始媒体只读。

## 本地更新

`scripts/deploy_mixed_media.py` 仅使用标准库（可选 `psutil` 进程检测）显式同步包含 `system/dinov3/video.py` 与 `system/dinov3/video_reference.py` 在内的 16 个后端、脚本与文档文件，不覆盖模型权重、校准包、学习档案、界面程序或历史数据；默认不改动 `temp/settings.json`，仅在显式传入 `--enable-fast-video` 时修改 `video_mode` 为 `fast` 并保留原配置备份与失败／手动回滚能力。
