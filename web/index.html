关于 Neri Web
NERI Enables Rapid Identification · 红外相机图像智能处理工具网页版

版本：Neri Web Edition (MD3 Expressive · MegaDetectorV6 LiteRT 本地推理版)

核心特性：

  • 浏览器本地推理：基于 MegaDetectorV6 LiteRT (.tflite) 在浏览器端直接检测野生动物、人员与车辆，无需上传任何照片至云端服务器，保护监测数据隐私。
  • 断点自动恢复：利用 IndexedDB 本地持久化存储处理进度、目标边界框、预览缩略图与人工标记结果，意外关闭标签页或浏览器后重新打开即可无缝继续。
  • 物种名录联动：内置 2026 版《中国生物物种名录》（鸟纲/哺乳纲共 2,252 种），人工标记后一键批量导出包含学名、目、科、属及独立探测首只的 CSV 表格。
