## 二、软件功能与运行方式

1. Neri 提供本地影像导入、模型推理、结果预览、人工校验、标记、整理和导出等功能。
2. 模型识别结果可能存在误报、漏报或分类错误，不能替代人工复核、专业调查结论或依法需要的判断。
3. 软件可能启动仅监听本机地址的 Python 服务，用于处理文件、保存设置和执行任务。除本协议明确说明的网络功能外，核心影像处理在您的设备上完成。
4. 软件更新、依赖下载及第三方模型可能适用其各自的许可证和隐私规则。您应根据用途核实相应授权。

1. 您应具有接受本协议并处理所选数据的民事行为能力和合法权限。未成年人应在监护人指导和同意下使用。
2. 您应确保对导入、标记、导出或提交的照片及相关数据拥有合法来源、必要授权或其他有效处理依据。
3. 您不得利用本软件侵害他人的隐私、肖像、著作权、商业秘密或其他合法权益，不得处理或传播违法内容。
4. 您应妥善保管原始影像和研究成果。Neri 不是备份服务；删除、移动或覆盖文件前，请自行完成可靠备份。

## 四、本地处理的数据

为实现核心功能，Neri 可能在您的设备上读取或生成下列数据：

1. 您主动选择的照片、视频、文件夹及其本地路径；
2. 模型推理结果，包括候选物种、置信度和目标框；
3. 您作出的确认、物种名称、数量、类型、收藏状态、空照片标记和备注；
4. 处理任务、导出偏好、模型路径、界面偏好、日志和运行诊断信息；
5. 软件版本、操作系统、硬件和依赖状态等为运行与排错所需的技术信息。

这些数据通常保存在本机项目目录、输出目录、应用数据目录或缓存中。卸载软件不一定会自动删除您另行保存的结果、日志或输出文件，您可以通过系统文件管理功能处理它们。

## 五、模型改进计划概述

1. 模型改进计划用于训练、评估和改进野生动物识别模型。
2. 该计划默认关闭。只有在您阅读披露内容、同意本协议并明确选择“同意参加”后，本地服务才会建立和执行提交任务。
3. 您选择“暂不参加”后仍可使用全部核心功能，软件不会通过重复启动提示催促您加入。您以后可以在“设置—隐私与数据”中再次查看完整披露并主动启用。
4. 参加后，提交在后台自动进行，不会在每张照片上传前重复询问。因此，请在加入前确认下述范围，并持续对您之后的人工标记负责。

## 六、参加计划时会提交的内容

只有参加计划后，Neri 才会处理下列后续数据用于提交：

1. **人工确认的物种照片。** 仅限您在参加之后明确完成物种确认的照片，以及相应的物种标签和为训练所需的边界框等结构化标注。模型预测框会明确标记为模型预测，不会被表述为人工确认框。
2. **人工确认的空照片。** 每个物理来源文件夹最多提交前 3 张经您确认的空照片。配额和完成历史会在本机持久保存，以避免重启后重复计算。不同物理文件夹分别计算。
3. **多物种照片。** 一张照片被确认包含多个物种时，会在每个对应物种分类下分别保存同一照片和配套标注；配套标注会包含该照片的全部物种标签。
4. **必要技术字段。** 可能包括随机样本编号、修订号、应用或模型版本、图像尺寸，以及区分人工确认与模型预测所需的字段。

以下内容不在计划提交范围内：

1. 视频文件或从视频批量扫描得到的媒体库内容；
2. 未经您后续人工确认的照片；
3. 您的本地文件路径、原文件名、GPS 精确位置、EXIF 元数据和自由文本备注；
4. 与训练无关的设备标识、账户密码或其他本机文件。

## 七、压缩、筛选与隐私限制

1. 待提交照片会在本机重新编码为 JPEG，长边不超过 2048 像素，编码质量为 82。该副本仅用于提交，不修改您的原始照片。
2. 重新编码会移除提交副本中的 EXIF 等元数据；配套标注采用允许字段清单，不包含本地路径、GPS 或备注。
3. 被明确标记为明显人物或车辆类别的照片不会进入提交队列。
4. 上述措施不能保证移除画面中可见的人脸、车牌、住宅、屏幕文字、签名、时间戳、水印或其他身份线索，也不能保证照片已不可逆匿名化。自动模型可能误判或漏判。
5. 在确认照片前，您应自行检查画面内容。请勿提交含有第三方敏感个人信息、私密活动、儿童清晰影像、受限设施或其他您无权共享内容的照片。

## 八、自动提交、队列与撤回

1. 参加计划后，您之后保存的符合条件的人工确认会创建轻量任务。后台工作程序会在短暂等待后生成压缩副本和标注，并尝试传输。
2. 网络中断或服务暂时不可用时，等待和失败任务可能保留在本机并自动重试。您可以在“设置—隐私与数据”查看待处理、上传中、已上传、失败和跳过数量。
3. 您可以随时停止参加。停止后，本地服务会在下一次传输前取消等待中或进行中的任务，并停止为新的确认创建提交任务。
4. 您可以单独清除尚未完成的等待或重试任务。清除不会重置已经完成的空照片配额或提交历史。
5. 已完成的远程提交不会因停止参加、清除队列或卸载软件而立即删除；它们适用本协议第十一条所述最长 365 天保存期限。您也可以通过本协议所列邮箱申请提前删除。

## 九、远程存储与跨境处理

1. 训练数据存储在运营者控制的 Microsoft OneDrive 目录中，并按安全物种名称及随机样本编号组织。
2. 参加后，Neri 会在本机后台压缩照片、去除照片元数据，再上传至运营者的 Microsoft OneDrive。服务器用于授权、校验固定上传目标、管理上传状态和提交记录；桌面端不能指定任意远程路径或上游地址。
3. Microsoft 可能通过位于中国境外的全球基础设施处理、传输或存储这些数据。选择参加计划即表示您理解并同意为模型改进目的进行此类跨境处理。
4. Microsoft 的数据处理适用其隐私声明：<https://privacy.microsoft.com/zh-cn/privacystatement>。
5. OpenList 可能在服务端作为在线 OAuth 授权辅助工具或存储接口管理工具，处理取得 OneDrive 授权和管理固定目录所需的信息。服务器负责授权、上传状态和提交记录管理，训练照片的存储目标为运营者的 Microsoft OneDrive；OpenList 不改变本协议约定的训练用途和固定存储范围。

## 十、处理目的与使用范围

提交的数据仅用于：

1. 训练、验证、测试和改进野生动物识别、检测和分类模型；
2. 评估不同环境、设备、物种和场景下的模型表现；
3. 识别数据或标注质量问题、排查提交故障并维护训练数据集；
4. 防止滥用、重复提交和未经授权的路径或文件操作。

运营者不会将计划数据用于广告画像、无关营销或出售个人信息。模型及统计结果可能被发布或用于研究，但不应以公开原始照片或重建个人身份为目的。

## 十一、保存期限与删除

1. 本地隐私选择、样本随机标识、空照片配额、任务状态和必要历史会在您使用相关版本期间保存，以执行选择、避免重复和处理撤回。
2. 远程未完成上传尝试在创建满 20 分钟后进入清理，服务器约每 5 分钟检查一次。已完成的照片和配套 JSON 标注自相应修订创建之日起按最长 365 天（不超过 12 个月）的保存周期处理；正常服务下到期自动清理，因网络或存储服务故障未完成的清理会在恢复后重试。
3. 当处理目的提前结束、您提出有效删除请求、运营停止或法律要求更早删除时，运营者将在完成身份和请求范围核验后提前删除相应可定位数据。
4. 法律法规要求继续保留的记录将在限制使用后按要求保存；此类例外不用于延长远程训练照片和配套 JSON 标注的常规保存期限。
