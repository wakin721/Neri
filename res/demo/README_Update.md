# 📜 Neri 更新日志

---

## ✨ Neri 3.0.4-beta(021b75) 更新日志 (2026.05.25)

1. 🚀 **任务增强**：后端任务创建接口新增 `input_paths` 列表输入，支持一次传入多个图片、视频或文件夹路径；物种校验界面的批量重新检测改为一次提交列表任务，视频文件也会在同一任务中按列表逐个识别。

2. ✅ **体验优化**：任务进度中的不确定进度条不再触发标题栏下方的全局加载条，避免任务启动/停止过渡状态让全局界面持续显示加载。

3. 🔧 **环境维护**：PyTorch 安装环境新增 CUDA 13.2 选项。

4. 🔧 **安装源优化**：手动选择阿里源或清华源安装 PyTorch 时，会在 PyTorch wheel 源后追加 `-i` 镜像地址；安装 ultralytics 和重新安装单个 Python 包时也统一使用 `-i` 指定镜像源。

> **⚠️ Warning：** 部分avi格式视频可能无法识别，暂不支持windows7系统。对intel gpu的支持为实验性，在部分电脑上可能会报错。

## Neri 3.0.3-beta 更新日志 (2026.05.23)

1. 🖍️ **内容更新**：设置页“软件更新”顶部新增当前版本信息；“项目信息”调整为“关于”，并提供版本号、更新说明、反馈建议和源代码入口；连续点击版本号可开启调试模式。

2. 🧪 **调试增强**：新增调试模式页面，可查看前端版本、后端版本、后端地址、运行平台、GPU/PyTorch 状态、YOLO 依赖状态；支持复制调试信息、查看已安装 Python 库以及读取软件日志，便于定位环境和依赖问题。

3. ✅ **体验优化**：优化启动连接后的全局加载状态，尽量等待初始页面数据加载完成后再关闭加载条；优化程序关闭流程，在 Python 后端已关闭或不可用时减少退出等待；未检测到可用 GPU 时自动禁用 FP16；开始界面删除任务提示改为显示处理路径和当前状态。

4. 🧭 **校验优化**：校验界面的物种分组会按当前置信度重新计算，低于阈值而被过滤的检测会归入过滤后的分组；当整组照片都低于阈值时直接显示为“空”，避免继续停留在原物种分组。

5. 🔧 **问题修复**：修复 Windows 端连接后端后可能闪退的问题；修复后端父进程监听在部分权限场景下可能误判退出的问题；调整主界面页面承载方式，降低 Windows 可访问性树更新异常对界面的影响。

> **⚠️ Warning：** 部分avi格式视频可能无法识别，暂不支持windows7系统。对intel gpu的支持为实验性，在部分电脑上可能会报错。

## Neri 3.0.2-beta 更新日志 (2026.05.20)

1. 🖍️ **内容更新**：校验界面支持批量撤回，可一次撤回最近多步校验操作；设置 → 基础设置新增“撤回步数”配置，支持设置一次撤回的步数；后端新增批量校验标记接口，用于快速标记、批量标记和批量撤回。

2. ✅ **体验优化**：快速标记和批量标记改为批量提交，减少大量单项请求导致的加载末尾卡顿；校验界面空状态下，“重新获取”按钮会在加载时显示加载状态；检测依赖未安装时，检测设置中的“安装依赖”会弹窗确认并自动检测安装，不再跳转到环境维护；开始界面在检测依赖未安装时，会禁用模型文件、分类模型、视频处理、FP16、置信度、IOU 等检测相关设置；校验界面“其他”按钮高度与刷新/撤回按钮保持一致，物种按钮和数字按钮恢复原高度。

3. 🔧 **问题修复**：修复撤回只能撤回上一步的问题；修复校验界面部分按钮高度不一致的问题；修复检测依赖缺失时，设置页安装路径不够直观的问题

> **⚠️ Warning：** 部分avi格式视频可能无法识别，暂不支持windows7系统。对intel gpu的支持为实验性，在部分电脑上可能会报错。
