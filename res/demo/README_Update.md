## ✨ Neri 3.0.5-alpha2(b5f6a6) 更新日志 (2026.07.14)

1. 🧭 **Windows 托盘交互**：托盘图标悬浮时会显示 `Neri`；存在运行中、暂停或失败的任务时，会同步显示任务状态、完成百分比和已处理数量，修复此前托盘提示为空白的问题。

2. 🎛️ **托盘快捷控制**：左键单击托盘图标可打开快捷菜单，并根据当前状态直接开始、暂停或继续任务；也可从菜单进入设置或退出 Neri。进入设置和退出确认时会自动恢复并聚焦主窗口。

3. 📊 **任务栏进度显示**：批处理期间，Windows 任务栏图标下方会实时显示处理进度；任务尚在准备时显示不确定进度，暂停和失败状态使用对应的任务栏状态颜色，任务结束后自动清除进度。

4. 🧾 **日志目录统一**：崩溃监控、启动异常报告、后端环境维护和 YOLO 运行日志统一保存到项目 `logs` 目录，减少日志分散在 `temp` 或系统临时目录而难以查找的问题。

5. 🧹 **日志维护兼容**：软件日志查看与清理流程统一以 `logs` 目录为准，同时保留对旧版 `temp` 崩溃报告的读取和遗留日志清理能力，升级后仍可处理已有诊断文件。

> **⚠️ Warning：** 部分 avi 格式视频可能无法识别，暂不支持 Windows 7 系统。对 Intel GPU 的支持为实验性，在部分电脑上可能会报错。

## ✨ Neri 3.0.5-alpha1(7dfa6c) 更新日志 (2026.06.17)

1. 🚀 **视频并发处理**：检测设置新增线程数配置，完整视频跟踪任务可按保守线程数并发处理多个视频，并在进度信息中显示并发 worker 状态。

2. ⚙️ **批处理设置优化**：前端请求新增 `thread_count` 参数；批处理数与线程数分离，CPU 模式下不再强制锁定批处理数，仅继续禁用 FP16。

3. ✅ **校验分组优化**：物种校验分组不再因视频文件本身强制断组，展开后的分组标题更简洁；媒体类型判断统一扩展支持 `m4v` 与 `ts` 视频。

4. 📦 **模型更新**：合并新增模型 `11s_p2_0319.pt`，为 3.0.5 alpha 阶段提供新的内置检测模型候选。

5. 🛠️ **数据写入增强**：SQLite 批量检测与校验写入会过滤空文件名、规范化写入数据，并在批量写入失败时记录日志，便于排查导出或校验同步问题。

> **⚠️ Warning：** 部分 avi 格式视频可能无法识别，暂不支持 Windows 7 系统。对 Intel GPU 的支持为实验性，在部分电脑上可能会报错。

## ✨ Neri 3.0.4-release(dfc280) 更新日志 (2026.06.16)

1. 🚀 **稳定版整合**：整合 3.0.4 alpha 与 beta 阶段的批量检测、视频处理、校验流程、导出维护、崩溃记录和环境维护更新，作为 3.0.4 稳定版发布。

## ✨ Neri 3.0.4-alpha1(b986e9) 更新日志 (2026.05.26)

1. 🚀 **任务增强**：后端任务创建接口新增 `input_paths` 列表输入，支持一次传入多个图片、视频或文件夹路径；物种校验界面的批量重新检测改为一次提交列表任务，视频文件也会在同一任务中按列表逐个识别。

2. ✅ **体验优化**：任务进度中的不确定进度条不再触发标题栏下方的全局加载条，避免任务启动/停止过渡状态让全局界面持续显示加载。

3. 🔧 **环境维护**：PyTorch 安装环境新增 CUDA 13.2 选项。

5. ⚡ **检测性能优化**：默认关闭增强推理，减少连续批次检测中的重复推理开销；GPU 缓存清理改为按显存压力自适应执行，降低频繁清理导致的批次间等待时间。

6. 🧠 **显存管理**：检测结果返回前转移到 CPU，停止任务、取消任务和任务结束后会主动清理 GPU 缓存，减少显存占用堆积和停止后残留。

7. 📊 **进度显示**：任务进度新增处理速度、已用时间和预计剩余时间显示，便于观察批量检测和视频处理效率。

8. ⚙️ **检测设置**：设置 → 检测设置新增输入尺寸 `imgsz`，支持调整 YOLO 推理尺寸，滑块步进为 160。
