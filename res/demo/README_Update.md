## ✨ Neri 3.0.5-release(8c544f) 更新日志 (2026.08.23)

5. 🔄 **更新与环境维护**：新增稳定版与预览版通道，支持 Neri 国内源与 GitHub 官方源自动选择、断点续传、SHA-256 校验和安全覆盖更新，同时强化 Python 依赖安装、重试与损坏环境修复。

## ✨ Neri 3.0.5-beta7(58b040) 更新日志 (2026.07.27)

1. ⚡ **视频抽帧与推理提速**：快速视频模式会并行准备多个视频，并将抽取帧按批次送入模型，减少逐帧调用造成的 GPU 空转；只抽取少量帧时优先采用稳定的顺序解码，降低频繁跳转在部分编码格式、机械硬盘和网络目录上的额外开销。

2. 🎞️ **视频处理稳定性修复**：抽取帧统一写入临时图片后再进入推理管线，并限制并发解码数量与待处理内存；修复视频批处理直接卡死、临时帧生命周期异常，以及单个视频失败影响整个批次的问题。

3. 📝 **批处理日志与自动清理**：每次批处理会生成独立日志，记录输入规模、运行参数、抽帧与推理耗时、错误和完成状态；默认仅保留最近 5 个日志并自动删除旧记录，便于定位速度与兼容性问题。

4. ⭐ **收藏媒体同步导出**：物种校验界面现在可以收藏视频；导出表格时可按设置询问、始终同步或不同步收藏媒体，并将收藏的照片和视频复制到独立目录。

5. 🗑️ **空照片删除与安全确认**：基础设置新增“询问、不删除、删除”三种导出后处理方式；选择删除且存在尚未人工校验的空照片时，会显示同样式的二次确认。后端仅删除本次输入中明确选中的照片，修复导出成功后空照片未同步删除的问题。

6. 🪟 **重复启动提示统一**：Windows 单实例启动会恢复并切换到已经打开的 Neri 窗口，并在现有应用内显示 Material 3 风格提示，避免重复启动时出现原生弹窗或窗口未置前。

7. 🛠️ **依赖安装与软件更新增强**：PyTorch 安装增加长路径预检、损坏安装修复、网络超时与重试；更新包改为在应用内计算 SHA-256，并自动定位可用的 Windows PowerShell，提升安装和覆盖更新的成功率。

8. 🏗️ **Windows 构建流程修复**：恢复 `dev` 分支推送后的自动构建，并进一步统一构建目录、可执行文件与产品元数据中的 `Neri` 名称，避免打包阶段回退为工程名。

> **⚠️ Warning：** 自动下载安装目前仅支持 Windows；部分 avi 格式视频可能无法识别，暂不支持 Windows 7 系统；Intel XPU 安装与自动启用目前已暂时关闭。
